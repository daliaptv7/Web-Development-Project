#  Casa Marina Sulina - Proiect Atestat Web Development

Proiect web de prezentare pentru pensiunea **Casa Marina Sulina**, realizat ca lucrare practică pentru Atestatul de Competențe Profesionale la Informatică.

---

##  Despre Proiect

Site-ul oferă turiștilor o experiență interactivă de navigare pentru explorarea opțiunilor de cazare, a facilităților oferite și a posibilităților de agrement/excursii în Delta Dunării (Sulina).

###  Tehnologii Utilizate
* **HTML5** – Structura semantică a paginii web
* **CSS3** – Stilizare responsive, layout-uri moderne și animații
* **JavaScript (Vanilla)** – Elemente interactive și dinamică în pagină
* **Font Awesome** – Pictograme vectoriale

---

##  Structura Fișierelor

* `index.html` – Pagina principală a site-ului
* `*.jpg` / `*.png` – Galeria foto cu camerele, facilitățile și excursiile din Sulina
